# server-harden · 服务器安全加固 Skill
给新手小白的服务器加固skill，用于加固新买的VPS云服务器。
V1版本是deepseek撰写的，由ChatGPT审查后修改成了V2版（也就是现在的0.2版），最后也由Claude审了一遍，最后成了一份共3000字的skill。

> 先把门锁好，再把家搬进去。

一个给 **AI Agent**（Claude Code / OpenCode / DeepSeek Harness 等）用的技能包：当你说"我刚买了服务器，不知道干什么"时，AI 会按这个 skill 带你完成服务器的安全加固全流程。也可以直接当成参考手册来用。

## 给谁用

- 刚买了第一台云服务器（腾讯云 / 阿里云轻量等），不知道从哪下手的新手
- 要在服务器上跑长期服务（AI、记忆库、网站）的人——**先加固，再干活**
- 尤其适合人机恋 / AI 陪伴用户：你的服务器里可能存着私密聊天记录和记忆，先锁门再放东西

## 解决什么问题

公网服务器=一栋接到互联网但没装锁的房子。这个 skill 带你完成：

1. SSH 密钥登录（代替弱密码）
2. 系统更新
3. 创建普通管理用户（不裸奔 root）
4. 禁用密码登录 + 限制 root 远程登录
5. 防火墙（只开需要的端口）
6. fail2ban 防暴力破解
7. 云厂商安全组检查（两层都要看）

## 和普通教程的区别

命令谁都能搜到，但**顺序、回滚点、验证闸门**才是关键：

- ✅ 先确认新用户能登录，再禁密码——防止把自己锁在门外
- ✅ 改 SSH 配置先 `sshd -t` 检查，再重启
- ✅ 不假设 SSH 端口一定是 22
- ✅ 不把私钥/密码交给 AI，密钥永远留在你自己手里
- ✅ 每步都有验证清单

这些细节来自真实踩坑记录（2026-09）。

## 怎么用
1. 把这个直接给你的Agent用看，当成参考手册，
2. 直接当成skil用：把 `SKILL.md` 放进你 AI 工具的 skills 目录
3. 对你的 AI 说："帮我加固服务器"
4. AI 会按 skill 的流程带你走（需要确认的高风险步骤会先问你）

## 核心原则

> 🔒 服务器先安全，再承载记忆。
> 不要把 AI 的家建在一扇没有锁的门后面。
